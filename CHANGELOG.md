# Changelog

Each version is a GitHub Release with the deck, its manifest and `capital_points.tsv` attached. Import a new
version over the old one to update it (see the README).

## 2026-11-22

The first version: the world's countries, territories and first-level subdivisions - 4,111 notes in
`World in Flashcards::Regions` (280 countries and territories, 3,829 subdivisions, 2 other areas).

- Cards: flag and emblem to place (up to five flags and two emblems), map to place, capital to place, place to
  capital, place to flag, and tap the place on a map.
- Native names with IPA and recordings, English recordings, capital dots on the maps, and the region's
  languages, codes, currency, calling code and top-level domain under "More about" on every back.
- Built from the data repository's tag `deck-2026-11-22`.
